# 📈 Gold Price Analysis

A data-driven project that analyzes and visualizes **Gold Price trends** using Python and Jupyter Notebook.  
It explores historical data, performs analysis, and provides insights for better understanding of gold price movements.  

---

## 🚀 Features
- 📊 **Exploratory Data Analysis (EDA)** on Gold Price dataset  
- 📉 Trend visualization with Matplotlib & Seaborn  
- 🔍 Insights on historical patterns  
- 🧮 Simple, clean and easy-to-understand notebook  

---

## 🛠️ Tech Stack
- **Python 3**
- **Jupyter Notebook**
- **Pandas, NumPy**
- **Matplotlib, Seaborn**
